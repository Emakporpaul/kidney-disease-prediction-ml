How it works
01
Enter lab values
Fill in the 24 clinical markers from a patient's urinalysis and blood panel. Empty fields are imputed using training-set statistics.
02
Preprocess & encode
Values are cleaned, label-encoded, and scaled using the same pipeline used during training — preventing data leakage at inference time.
03
Random Forest inference
The best-performing model (98.75% accuracy, 100% recall) runs inference via a FastAPI endpoint hosted on Hugging Face Spaces.
